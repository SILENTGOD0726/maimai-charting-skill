# simai 原生记谱速查（2026-11-08 核对）

> 来源为 simai 记谱定义者 Celeca 的 Wiki（持续更新到 2026 年）；这是**simai 原生记法**，不应与某款模拟器的全部私有扩展混为一谈。符号例子是简短的新编例示。

## 1. 时间轴

- 按钮：1 位于右上方约 1 点钟方向，顺时针 1–8。
- `,`：推进当前音符网格的一个单位；连续 `,,` 表示空拍。
- `(174){16}`：当前 BPM 174、十六分音符为一个逗号网格；先写 BPM，再设网格。
- `{#0.35}`：直接指定每个网格推进 0.35 秒，不再需要配套细分参数。
- BPM 和网格可以在谱面中切换；注意是从变更位置往后生效。
- `&first`：simai 原版播放器的音频/谱面起始偏移参数，具体解释与播放器需核实。
- `E`：独立结束记号，不是 E1/E2 等 TOUCH。需放在最后持续任务名义结束之后，并根据目标工具留出结束余量；换行本身不推进时间。
- 每逗号时长为 `240 / BPM / 分音数` 秒；例如120 BPM、八分网格为0.25秒。普通相对网格需要明确BPM；`{#0.35}` 则直接定义秒数。

## 2. 基础 Note

| 类型 | 例子 | 解释 |
|---|---|---|
| TAP | `1,` | 1 号按钮 TAP |
| BREAK TAP | `1b,` | 带 BREAK 的 TAP |
| EX TAP | `1x,` | EX 记法 |
| HOLD | `5h[2:1],` | 5 号按钮，1 个二分音符时值 |
| BREAK HOLD | `5bh[2:1],` | BREAK HOLD（`hb` 也可以） |
| TOUCH | `B1,` | B 组第 1 传感区 |
| TOUCH | `C,` | 中心触摸区；`C1`/`C2` 在原生记法中等价 |
| TOUCH HOLD | `Ch[4:3],` | 中心 TOUCH HOLD，3 个四分音符 |
| Touch 烟花 | `B7f,` | TOUCH 带花火特效 |
| TOUCH HOLD 烟花 | `Chf[1:2],` | TOUCH HOLD 带花火特效 |
| EACH | `1/5,` | 两个同时命中的音符 |
| BOTH/TAP EACH | `15,` | 仅 TAP+TAP 可省略 `/`；含 BREAK/HOLD/SLIDE 不能省略 |

注意：原生格式允许 A/B/D/E 组编号 TOUCH；原生 Wiki 2026-03-24 更新称 PRiSM PLUS 起已有中心外的 TOUCH HOLD。不同游戏版本与第三方引擎的支持范围未必一致。

## 3. 时值

- `[2:1]`：以当下 BPM 为基准的“一个二分音符时长”。
- `[#5.678]`：直接指定 5.678 秒的 HOLD 时长。
- `[150#2:1]`：以 BPM 150 解释 `[2:1]`。
- 对 SLIDE 而言，`[8:3]` 是**移动时长**，另有出发前等待；不能把 `[8:3]` 解释成 SLIDE 星形起点到结束的全部时间。
- 普通SLIDE默认等当前BPM的一拍，再开始移动。120 BPM的 `1-4[8:3]` 等0.5秒、移动0.75秒，总名义占用1.25秒。
- `[160#8:3]`：等待按160 BPM的一拍（0.375秒），移动为160 BPM的三个八分（0.5625秒）；不是仍按当前120 BPM等待。
- `[160#2]`：等待0.375秒、移动2秒。
- `[3##1.5]`：等待3秒、移动1.5秒；`[3##8:3]`：等待3秒、移动时长按当前BPM解释。
- `[3##160#8:3]`：等待3秒、移动按160 BPM的三个八分解释。
- 显式等待数值可为零；这不等于目标引擎必然支持，也不代表常规谱适合无引导秒滑。等待与移动、BPM、分母不能采用同一个数值校验条件。

## 4. SLIDE

| 轨迹 | 符号 | 说明 |
|---|---|---|
| 直线 | `-` | 如 `1-4[8:3],` |
| 外周 | `>`、`<`、`^` | 顺/逆方向及短弧，需根据几何表验证合法端点 |
| V 路径 | `v` | 经过屏幕中心 |
| 曲线 | `p`、`q`、`pp`、`qq` | 两类大小曲线 |
| 闪电 | `s`、`z` | 折线路径 |
| 大 V | `V` | 需要经过点，如 `1V35[8:3],` |
| 扇形 | `w` | 对角关系受限；不可任意配端点 |

- BREAK SLIDE：后缀 `b`，如 `1-4[8:3]b,`。
- 同起点多 SLIDE：`1-4[4:3]*-6[8:5],`。
- 连续 SLIDE：`1-4q7-2[1:2],`；若逐段指定速度，需为每段指定时长，如 `1-4[2:1]q7[2:1]-2[1:1],`。
- 统一总时值按整链恒定移动速度处理，各段按路径长度分配，不是等分总时间。逐段时值会改变经过中间点的时间，必须重新审查沿途输入。
- 星形起点替换：`1@-5[8:1],` 为普通 TAP；无起点星：`1?-5[2:1],` 或 `1!-5[2:1],`，显隐方式不同。
- 星形 TAP：`1$,`，旋转星 `1$$,`。

**关键：**原生规范存在“SLIDE 起终点合法性表”；上面只说明符号类别，未提供完整几何判定算法。创建不熟悉的轨迹时先核实原文的表，再在目标播放器检查。

## 5. 特殊语法

- EX：`1x,`、`3hx[2:1],`、`5bx,`（x/b/h 次序可变，前提是对应类型有意义）。
- 伪 HOLD TAP：`3h,`；伪 TOUCH：`Ch,`；原始文档描述为极短时值特例。
- 非真正同时的伪 EACH：``1`2,``，后续音符相对前一个略有延后。它**不计为真正 EACH**。
- 具体软件可能扩展自己符号；要优先用目标引擎解析器验证，禁止不加说明直接把扩展语法当作原生语法。
